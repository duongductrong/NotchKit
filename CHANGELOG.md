# Changelog

All notable changes to NotchKit will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-07-26

### Added
- Native macOS UI revamp for NotchDemo presets, walking pixel cat, and polished spacing.
- MorphExplorer interactive canvas workspace and floating tune panel.
- Interactive notch simulator for website application.

## [1.0.0] - 2026-07-20

### Added
- Initial release of NotchKit: Dynamic Island overlay library for SwiftUI on macOS 14+.
